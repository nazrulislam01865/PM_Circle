PM Circle signup prototype alignment + secure email verification
============================================================
Apply the ZIP contents into the existing PM Circle Laravel repository,
preserving relative paths. Back up/commit current changes first.

LOCAL ENVIRONMENT (in your existing .env):
APP_ENV=local
PMC_SIGNUP_EMAIL_CODE_REQUIRED=true
MAIL_MAILER=smtp
MAIL_HOST=<your SMTP server>
MAIL_PORT=<your SMTP port>
MAIL_USERNAME=<your SMTP login>
MAIL_PASSWORD=<your SMTP password>
MAIL_FROM_ADDRESS=<your verified sender>
MAIL_FROM_NAME="PM Circle"

Use the appropriate MAIL_SCHEME (or SMTP provider settings) for TLS.
Never commit .env or SMTP credentials. MAIL_MAILER=log is NOT email delivery.
APP_KEY must remain stable for verification and session security.

VERIFY IN YOUR LOCAL REPOSITORY:
php artisan config:clear
php artisan route:clear
php artisan migrate:status
php artisan test --filter=SignupEmailCodeTest
php artisan test
npm ci
npm run types:check
npm run build
php artisan serve
