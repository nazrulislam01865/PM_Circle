# AI Resume Assistant profile tab and CV template

Source: Archive 5(1).zip and the supplied four-page Word résumé. Only the template structure and appearance are reused; no personal example content from the document is included.

- Shared `ProfileWorkspaceHeader` preserves the original My profile title, actions, existing tab labels and CSS. Adds an entitled-member AI Resume Assistant tab; the existing sidebar shortcut points to it. The legacy GET and POST routes remain available.
- Profile tab is `/settings/profile?tab=assistant`. It checks the same verification, onboarding and plan requirements before accessing assistant data. Existing import and AI request services remain unchanged.
- CV preview and existing printable/Word export follow the supplied template's centered name/contact header, neutral typography, ruled section headings, section order, stacked entry details, bullets, skill/language/interest rows, achievement rows and A4 paper. The preview measures blocks locally and groups them into pages; extremely large individual blocks may expand a page rather than clip. Source Sans Pro/Source Sans 3 use installed fonts if available, otherwise the app font (preview) or Arial (export). Word remains the existing HTML-based `.doc` export; PDF remains browser print. Pagination and font rendering may differ from the original Word file.
- Repeatable education, work, research, university projects, skills, achievements, interests, languages and certifications are editable. Contact fields include phone, headline, portfolio, GitHub, LinkedIn. No template personal data is seeded. Current profile name, email, role, location and summary are reused. Email remains read-only; existing account editing manages it.
- Submitted full CV is encrypted in the new nullable `profiles.private_resume_document` column; hidden from ordinary model serialization. A draft is saved in the existing encrypted session. Submit updates shared basic profile details and saves the independent CV, leaving public experience/education/project/credential records and privacy unchanged. Old submit payloads remain supported. Existing profile export uses saved CV if available, otherwise maps current profile data to the template. Export includes saved data, not unsaved edits. AI analysis/rewrite operates on existing uploaded CVs and requires consent; work-experience suggestion targets the first entry. Existing import workflow does not automatically extract new template-specific categories.
- Data bounds: 20 entries per section, 4,000 characters per multiline field, 255 for short fields, total JSON document limit 150,000 bytes. Existing profile collections are not deleted or replaced.

## Deploy
Back up database and application, apply patch to project root, run `php artisan migrate --force`, `npm ci`, `npm run types:check`, `npm run build`, `php artisan optimize:clear`, using project's supported Node version. Do not replace the environment or uploaded files. Run `php artisan test --filter=ResumeAssistantBuilderTest` on the test database. Test editing/saving/reopening, guest/Plus restriction, exports and AI consent.
