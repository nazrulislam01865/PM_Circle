# Learning catalog control and lesson knowledge checks

## Admin workflows

- **Browse Courses control** in the admin sidebar, or Course library > Browse Courses settings, edits the catalog heading, recommendation card title/description/button and visibility, topic shortcuts visibility, search placeholder, course details button and empty state. The existing category/level master data, published course records and four-card layout remain authoritative. The three-question recommendation algorithm and filter semantics are unchanged.
- **Course library > Edit > Lessons & lectures**: create a lesson, select its curriculum section/topic, enter the reading content, optional direct HTTPS video URL, key takeaway, when to apply it, example, references and application. Optional lesson Q&A is authored by staff. Save the course to assign stable lesson UUIDs.
- Click **Manage lesson questions** beside a saved, linked lesson. Add a single MCQ or import Excel/CSV. Select the target lesson before importing. The section and topic can be left empty in the file for a selected lesson, or must match its saved placement. Select an answer A-D explicitly, write an explanation and publish when ready. Draft questions stay private. Existing course-wide practice settings are unchanged.
- The existing 13-column Excel template remains compatible. The scenario CSV template adds `Scenario Text` and `Scenario Video URL` after the `Publish` column. The importer also accepts .xlsx using those exact 15 headers. Up to 500 rows / 5 MB, atomic validation and unique question IDs per course. Use direct browser-playable HTTPS video URLs (for example, MP4); embedding YouTube watch pages and private video-file upload are not implemented. Use a trusted media host and avoid sensitive information in URLs. A video link is sent only to eligible enrolled members through lesson/practice data, but external media is subject to its own hosting permissions.
- Use **Manage lesson documents** to upload lecture resources through the existing private file flow. Existing resource authorization is preserved.

## Member behavior

All published lesson-specific questions are returned in one query and checked using the existing authenticated, enrollment-checked, lesson-key-checked endpoint. Correct answers and explanations are not present in the initial payload. Each MCQ has independent selection and feedback. Explicit lesson questions work independently of timed exam enablement. Legacy shared-topic questions still appear where they previously matched and course practice is enabled. Lesson-assigned questions can also enter the course's timed practice pool; scenario content is frozen in new attempt snapshots. Existing attempts remain readable. Knowledge checks are formative; completion and certificates are not gated by correctness and knowledge-check answers are not persisted as a separate attempt history.

The lesson FAQ replaces the previously unavailable Learner Q&A placeholder with staff-authored questions; no fictional learner records are created. The unavailable AI lesson assistant is hidden rather than displaying nonfunctional controls. Live AI lesson assistance and learner-authored discussion are not implemented by this change. Personal notes, course progress, certificates and documents continue to use existing services.

## Data and deployment

Migration `2026_11_26_000006_add_lesson_question_controls.php` adds nullable `lesson_uid`, `scenario_text`, `scenario_video_url` and a scoped index to `learning_course_questions`, plus singleton `learning_catalog_settings`. There is no destructive forward migration or seed requirement. Existing rows remain shared-topic questions. The admin validates course membership of lesson IDs, prevents deletion of lessons with attached questions and prevents relocating such a lesson before its questions are reassigned. Lesson FAQ content lives in existing lessons JSON and does not change progress hashes. Catalog controls add one settings read on actual Browse Courses requests only.

Preserve .env and private storage, back up the database, run `composer install`, `npm ci`, `php artisan optimize:clear`, `php artisan migrate`, `npm run types:check`, `npm run build`, `php artisan optimize`. Use a compatible Node version (22.18+ within 22.x).
