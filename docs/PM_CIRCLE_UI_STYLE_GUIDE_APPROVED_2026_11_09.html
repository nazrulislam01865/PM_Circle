PM Circle UI Style Guide

A compact system type scale for the simulator, feed, member pages, and forms. The result screen above shows the components in context. The CSS variables in this file are the source for the values below.

Typography

H4 · Card group heading

Paragraph text is used for explanations, feed posts, and longer instructions.

UI text is used for labels, navigation, and controls.

Small text is used for timestamps, breadcrumbs, and help.

Caption text is used for short metadata and chart labels.

Values assume a 16 px browser default. The CSS uses rem units. Choose heading levels by section hierarchy and use one H1 per page.
