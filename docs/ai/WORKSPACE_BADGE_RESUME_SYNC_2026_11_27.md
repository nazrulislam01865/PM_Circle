# AI workspace, latest badges and reviewed resume synchronization

## Scope
- AI Settings and Workspace continue to use the existing feature catalog and operation routing records. Workspace can enable/disable catalog features; PMP explanation/follow-up dependency is checked in all existing writers. Diagnostics resolve the selected saved operation and model; unsaved selections must be saved before testing. Fixed deployment safety switches, Daily Challenge scheduling/publication settings and Career Trend workflow/provider controls remain separate intentionally.
- Mandatory Daily Challenge moderation and the community admission check resolve the saved moderation route. Gemini/Anthropic retain the legacy default only when no dedicated assignment exists. Explicit disabled credentials fail closed. Explicit key lookups are scoped to one HTTP request/queue job and never cached in Redis.
- Home and profile Overview share the newest three earned badges using historical earned_at when available and actual award ledger creation time otherwise. Equal dates use ledger ID; no historical completion dates are fabricated. Revoked awards remain excluded. No additional badge queries.
- Submit profile in AI Resume Assistant merges the reviewed document into the existing profile records in the existing transaction. It retains independently verified credentials, existing unmatched entries, profile visibility, account email restrictions and the encrypted private CV. Draft/extraction/export do not publish or update repeatable records. Old API callers without explicit sync_profile consent keep their existing private-document behavior. Previously submitted private CVs may be reopened and submitted again. Matching is by section identity and, where known, normalized period; ambiguous identities require member review in Edit profile. No profile records are deleted by this workflow.

## Deployment
No schema changes or new dependencies. Stage first, retain a database backup and existing encrypted credentials. Build fresh assets (`npm ci`, `npm run types:check`, `npm run build`); `php artisan optimize:clear`, `php artisan optimize`, `php artisan queue:restart` (or restart the deployment's managed workers). Generated public/build assets from the input are deliberately excluded from the full source archive.

## Verification
Run Laravel feature tests for WorkspaceConnectionSelectionTest, FeatureSettingsTest, DailyChallengeModerationProviderTest, CareerTrendConnectionTest, ResumeAssistantBuilderTest and MemberAchievementsTest, plus the normal regression suite. Use non-production test credentials to test every configured operation, verify results on both settings screens and in a real queue job, submit a reviewed resume and check Overview/Edit, and verify the newest three badge cards on both pages. Live provider/database testing and full dependency-based frontend build must be completed on staging; the local container lacks vendor/node_modules and database drivers.
