# Admin-managed interview preparation

## Source and scope

Based on Archive 9.zip. Existing question bank, master-data options, sets, imports, member wizard, recorded answers, deterministic practice scoring and central AI review operation remain intact. No second interview bank, provider registry or credit wallet is introduced.

## Admin controls

Open `/admin/interview-preparation` from Administration > Interview preparation. Member options, Question sets and Question bank retain their existing CRUD and bulk import controls. In the question editor, optional topic, difficulty and suggested-answer guidance are now editable. Leave metadata blank to keep the old automatic inference / default rubric outline. CSV/XLSX import retains the existing four-column template; add optional metadata in the question editor after importing.

Open Practice settings to edit estimated minutes per question, new-session availability, job-description targeting, banner text, mix labels, requested mix percentages and role-specific professions/focus areas. The role selector edits one role at a time; Save settings saves the displayed configuration together. For the focus mix, the focus and common percentages must sum to at most 100%; the remainder is contextual questions. When a role has no focus areas, focus mode is hidden. Newly added roles inherit the previous defaults until customized. Industry scenario placeholder defaults, fixed answer-mode keys, rubric scoring mechanics, and common-only algorithm remain application rules; questions can use explicit scenario text instead of placeholders.

The AI answer review section links to `/admin/ai/workspace/features`, where the existing `interview_answer_review` operation owns enablement, model, credential assignment, fallback routing, daily limit, output-token limit, credit tariff and budget. The Workspace Configure action links back to Practice settings. Existing AI permissions apply to each administrative operation. Prompt editing uses the existing `ai.manage_prompts` permission. Publish and activate creates a new audited prompt version and atomically updates only `ai_features.prompt_version`; it rejects a stale expected version. Mandatory coaching scope, consent, membership, moderation and schema checks remain unchanged. AI review remains optional; local practice never invokes AI automatically.

## Data and performance

Migration `2026_11_27_000020_extend_interview_configuration.php` adds nullable `practice_settings` JSON to the existing single configuration row and nullable `topic`, `difficulty`, `answer_guidance` fields to existing questions. No data rewrite, new tables, seed duplication, or external dependencies. Default settings reproduce the previous setup. The member page reads the existing configuration row once; preview/start share a request-scoped configuration read. Question selection uses its existing bounded SQL ranking query, adding metadata to its projection. No per-question or per-role lookup. Focus areas are checked server-side against the current role profile. New sessions may be paused without affecting existing practice/results. Job-description disabling is enforced on both session selection and upload. Preview and practice payloads omit reference guidance; it is available to server-side feedback and optional AI review only after a saved answer. Existing draft snapshots remain eligible for their original 30-minute lifetime, subject to current option/role/availability validation. Existing started sessions retain question snapshots, timing and guidance. AI request instructions are pinned by the existing gateway.
